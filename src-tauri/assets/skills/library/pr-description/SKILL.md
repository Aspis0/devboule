metadata:
  author: devboule
  version: "1.0"
---
- **Summary**: One-line title summarizing the change.
- **Motivation**: Context on why this change is needed (problem statement).
- **Changes**: Bulleted list of what was modified, added, or removed.
- **Testing**: How the change was verified (manual steps, test names, screenshots).
- **Risks/Rollout**: Potential risks, dependencies, or rollout strategy (e.g., feature flag).
- **Checklist**: Ensure code is formatted, tests pass, and no debug code remains.
- **Keep it Skimmable**: Use headings and bullets for quick review by maintainers.
